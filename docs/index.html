VirtUI Manager

Manual GitHub Releases

TUI for managing QEMU/KVM VMs via libvirt. Built with Python Textual.

Install

pip3 install virtui-manager

Or from source:

git clone https://github.com/aginies/virtui-manager.git
cd virtui-manager/src/vmanager
python3 virtui_dev.py

Features

  • List VMs across local/remote libvirt servers
  • Start, stop, pause, resume VMs
  • VM configuration (CPU, memory, storage, network)
  • Snapshots and disk overlays
  • Bulk operations with regex patterns
  • VM cloning
  • Migration between servers
  • VM provisioning (Debian, Ubuntu, Fedora, Arch, Alpine, openSUSE/SLES)
  • Remote viewer (VNC/SPICE) with USB redirection
  • Web console (noVNC via websockify)
  • CLI tool (vmanager_cmd) for automation
  • Command pipelines
  • Backup management
  • No X11 required, works over SSH

Quick Start

  1. Connect to a libvirt server: virtui-manager
  2. Select a VM and use the Actions menu to start, configure, or migrate
  3. Press b for bulk operations across multiple VMs
  4. Use vmanager_cmd for CLI automation

CLI Example

$ vmanager_cmd
> connect localhost
(localhost) > list_vms
> select re:web-.* | start
